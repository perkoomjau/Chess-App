Chess App

A chess application written in C#.

The project consists of two separate components: ChessLogic, which handles the rules and state of the game, and ChessUI, which provides the graphical interface.

Project Structure

The solution is organized into two projects:

ChessLogic – Handles chess rules, legal moves and game states.

ChessUI – Handles the graphical interface and interaction with the game.

Both projects are included in Chess.sln.

Built With

C#

.NET

Visual Studio

Running the Project

Clone the repository:

git clone https://github.com/perkoomjau/Chess-App.git

Open Chess.sln in Visual Studio, set ChessUI as the startup project, and run the application.

Alternatively, build the solution from the terminal:

dotnet build Chess.sln
